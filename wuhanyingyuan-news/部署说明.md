## 一、部署步骤（服务器 121.40.198.41）

### 第 1 步：上传文件

把本目录（wuhanyingyuan-site）里的**全部文件**上传到服务器上 nginx 网站根目录（就是现在 index.html 所在的目录），注意新增的 `server.js`、`admin.html`、`news.html`、`article.html`、`css/news.css`、`js/news.js`、`js/admin.js` 都要传上去。

`data/` 和 `uploads/` 两个目录不用上传，服务启动后会自动创建。

### 第 2 步：确认服务器有 Node.js

```bash
node -v
```

如果没有安装（CentOS/阿里云示例）：

```bash
curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
yum install -y nodejs
```

### 第 3 步：启动文章服务

```bash
cd /你的网站根目录
nohup node server.js > news-server.log 2>&1 &
```

默认监听 `127.0.0.1:3789`，仅本机可访问，对外由 nginx 反代。

> 建议用 pm2 守护进程（可选）：`npm install -g pm2 && pm2 start server.js --name yy-news && pm2 save && pm2 startup`

### 第 4 步：修改 nginx 配置

在 `www.wuhanyingyuan.com` 的 server 块里，加入（放在现有 location 规则之前）：

```nginx
# 文章接口
location /api/ {
    proxy_pass http://127.0.0.1:3789;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
}

# 上传的封面图片
location /uploads/ {
    proxy_pass http://127.0.0.1:3789;
}

# 屏蔽数据目录和后台服务脚本
location ^~ /data/ {
    deny all;
    return 404;
}
location = /server.js {
    deny all;
    return 404;
}
```

然后重载 nginx：

```bash
nginx -t && nginx -s reload
```

### 第 5 步：立即修改管理密码（重要！）

登录服务器执行（把 `你的新密码` 换成自己的密码）：

```bash
cd /你的网站根目录/data
vi admin.json     # 把 "admin123456" 改成你的新密码，保存
```

改完无需重启服务。

## 二、日常使用

1. 浏览器打开 **www.wuhanyingyuan.com/admin.html**
2. 输入管理密码登录
3. 点「+ 新建文章」：填标题、分类、摘要，正文支持 HTML（`<h2>`、`<p>`、`<img>`、`<strong>` 等常用标签）
4. 封面图可直接上传（也会顺便存进正文可用的图片地址），或填外链
5. 勾选「立即发布」→ 保存，官网首页和新闻列表页即刻展示
6. 文章可随时「编辑 / 转草稿 / 删除」

---

## 三、数据备份

所有文章存在 `data/articles.json` 一个文件里，定期复制备份即可：

```bash
cp data/articles.json data/articles.backup.$(date +%F).json
```

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 首页新闻区显示「资讯准备中」 | 说明接口没通，检查第 3、4 步：`curl http://127.0.0.1:3789/api/articles` 应返回 JSON |
| 后台登录提示密码错误 | 检查 `data/admin.json` 内容是否被正确修改 |
| 服务意外停了 | 重新执行第 3 步；建议用 pm2 守护 |
| 上传图片失败 | 检查 `uploads/` 目录权限，Node 进程需要写权限 |
| 服务器重启后服务没起来 | nohup 方式不会自愈，建议用 pm2（见第 3 步注释） |
